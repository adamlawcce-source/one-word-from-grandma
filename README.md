One word: **witchcraft**.

The single word grandma would text about AI. She has watched a machine talk back and know things no machine should know, and her warm, baffled verdict is that it must be witchcraft. Funny in one word with no caption needed, tied to AI as mysterious machine-magic, and fresher than the obvious "robot" — a real grandmother's texting voice, not a tech word.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt`.
